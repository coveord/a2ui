# A2UI Basic Catalog

`@a2ui/catalog-basic` provides the Basic Catalog implementation for A2UI protocol v1.0.

```ts
import {basicCatalog} from '@a2ui/catalog-basic';
import {MessageProcessor} from '@a2ui/web_core_v1_0';

const processor = new MessageProcessor([basicCatalog]);
```

The package contains generated component and function APIs, Web Component implementations, catalog functions, theme support, and Markdown helpers. Run `yarn build`, `yarn test`, `yarn lint`, or `yarn format:check` from this directory.
